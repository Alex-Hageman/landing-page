# Alex Hageman — Personal Landing Page

A responsive personal landing page built with HTML5 and CSS3 as part of the BAIS:3300 Digital Product Management course at the University of Iowa. The site serves as a live "digital home" that goes beyond a static resume by demonstrating technical capability and communication skills through a functional web presence. It is designed for technical recruiters and hiring managers at large technology companies who need to quickly verify a candidate's analytical proficiency and ability to translate data into business value. The page features a hero section, bio, skills showcase, project portfolio, and contact footer — all without any frameworks or dependencies beyond a Google Font.

---

## Features

- Responsive single-page layout that adapts from 320px mobile screens to full desktop widths
- Sticky navigation bar with smooth-scroll anchor links to each content section
- Circular headshot hero with call-to-action buttons linking to projects and contact
- Teal pill badge skill tags distinguishing technical tools from analytical techniques
- Three project cards displayed in a responsive CSS Grid (one column on mobile, three on desktop)
